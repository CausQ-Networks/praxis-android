This is the official Praxis client with GUI for Android devices. 

This client can be used with both:

- [Praxis Cloud](https://app-praxis.causq.com/auth/login) - Quickest and easiest way to get started using Praxis.
- [Self-hosted Praxis](https://docs-praxis.causq.com/self-host/quick-install) - Fully self-hosted Community and Enterprise editions of Praxis.

## Download & Install

- [Praxis for Android](https://praxis.causq.com/downloads/android) - This is the official page to download the latest installer file for Android.
- [All Versions](https://github.com/CausQ-Networks/praxis-android/releases) - The releases section of this repository contains release notes and download artifacts for the latest version and all older versions.

## Compatibility

- Compatible with Android Android 7.0 (Nougat) or later

## Documentation

Documentation for the Android client and all other documentation for Praxis can be found at [docs-praxis.causq.com](https://docs-praxis.causq.com/manage/clients/install-client#android).
